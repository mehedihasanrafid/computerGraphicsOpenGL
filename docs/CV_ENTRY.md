## Portfolio summary

Yacht Journey is a C++17 and OpenGL application that animates a yacht through beach, mountain, city, and harbor scenes. The project demonstrates geometric modeling, affine transformations, hierarchical object construction, cubic Bézier curves, event-driven input, time-based animation, responsive viewport handling, and build automation. The repository is explicitly documented as a portfolio reconstruction of a collaborative university project.
